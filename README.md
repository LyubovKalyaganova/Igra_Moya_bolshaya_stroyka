# Моя большая стройка 3D

Детская образовательная 3D-игра для браузера. Возраст: 4–5 лет.

**Играть онлайн (эта ссылка открывается в Яндекс Браузере):**  
https://raw.githack.com/LyubovKalyaganova/Igra_Moya_bolshaya_stroyka/main/index.html

Сейчас готовы все этапы стройки: яма, самосвал, фундамент, стены, дом и свободная каталка на машинках.

## Как запустить

На телефоне и в Яндекс Браузере открывайте ссылку выше. Если появится короткое подтверждение перехода — нажмите, что согласны, затем **Играть**.

На компьютере можно также открыть файл `index.html` в Chrome, Edge или Яндекс Браузере.

Адрес GitHub Pages (`https://lyubovkalyaganova.github.io/Igra_Moya_bolshaya_stroyka/`) с части телефонов не открывается: соединение до GitHub не устанавливается.

## Управление

Экранные кнопки:

- ▲ вперёд
- ▼ назад
- ◀ ▶ поворот
- **КОПАТЬ**

Клавиатура для проверки взрослым:

- `W` / стрелка вверх — вперёд
- `S` / стрелка вниз — назад
- `A` `D` / стрелки — поворот
- `Пробел` или `E` — копать

Колёсико мыши слегка приближает и отдаляет камеру.

## Задание этапа 1

1. Нажмите **ИГРАТЬ**.
2. Подъедьте к жёлтому кругу.
3. Нажмите **КОПАТЬ** три раза.
4. Получите звезду, когда яма будет готова.
